Plawat Smart Band

A mobile experience for a connected smart band: pairing, provisioning, alerts and analytics across every band on an account.

The device hardware and firmware are built by SlimIOT’s device teams. My work is the software: the mobile app, dashboards, alerts and cloud sync.

01Overview

Plawat is a wearable health band. The app pairs and provisions the band, keeps its data in sync with the cloud and flags readings that need attention, for one device or several on the same account.

02Challenge

A wearable app gets harder as soon as one account owns more than one device. Each band has to be paired and provisioned, its readings synced without mixing devices up, and everything rolled up into a single account-level view. Abnormal readings also need to reach the user quickly, not only when they open a dashboard.

Key challenges

  • Keeping device identity and data separate while several bands sync to one account
  • Designing the data model so per-device readings aggregate cleanly at account level
  • Turning live readings into alerts without overwhelming the user

03My role

  • Implemented BLE pairing, device provisioning and cloud sync across multiple paired devices
  • Implemented custom alerts for abnormal health readings
  • Built real-time health analytics dashboards
  • Designed a scalable multi-device architecture with account-level data aggregation

04Solution

One app pairs and provisions each band over BLE, syncs every device’s readings to the cloud and aggregates them at account level. Real-time dashboards and custom alerts for abnormal readings sit on top.

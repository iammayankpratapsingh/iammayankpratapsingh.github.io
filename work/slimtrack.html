SlimTrack

The tracking app and the Node.js and MongoDB backend for a cellular GPS tracker, built and deployed by me.

01Overview

SlimTrack is a GPS tracker built on the nRF9161 DK cellular IoT module. It shows where a device is right now, raises alerts when it enters or leaves an area, and keeps the history of where it has been.

02Challenge

A cellular tracker sends small, frequent location messages over links that aren’t always reliable. The system has to take them in continuously, store a location history that can be queried, and turn raw coordinates into the answers people care about: where is it now, did it leave the area, where did it go today.

Key challenges

  • Ingesting a continuous stream of device messages over MQTT
  • Modelling location data in MongoDB so history, routes and trips are cheap to query
  • Owning deployment end to end: backend, database and broker running on Linode

03My role

  • Integrated the application with the nRF9161 DK cellular IoT module
  • Built the MQTT communication layer
  • Built the Node.js and MongoDB backend for device and location data
  • Delivered live tracking, geofencing with entry/exit alerts, route history and trip summaries
  • Deployed the full stack on Linode

04Solution

The nRF9161 DK publishes over cellular MQTT to a Node.js backend that stores device and location data in MongoDB. The mobile app turns that into live tracking, geofences with entry/exit alerts, route history and trip summaries. The full stack runs on Linode.
